# 发布说明

源代码包括 `seisdfe/`、必要的 `dinov3/` 核心、配置、测试、许可证和使用文档。
本地工作区原有的项目网页文件独立于 Python 软件包。

1. 使用有写权限的账号将源码发布到 `ProgrammerZXG/SeisDFE`。
   `.work/`、数据、实验输出和权重均不应进入 Git。
2. 按适用条款，将 `fault_dpt.pth`、`rgt_dpt_lora.pth` 和对应的 SeisDFE Stage-3 编码器
   单独上传为 Release 附件或模型托管资源。
3. 将真实下载链接写入 `docs/checkpoints.json`，并更新中英文权重状态表。
4. 发布后执行 CPU 工作流。完整预训练实验需同时保存原始语料索引、样本来源、硬件与批量设置。

代码仓库与模型资源分开发布。提交源码不会发布检查点；只有对应资源上传并核验后，才填写公开下载链接。

文档使用成对的英文、简体中文 Markdown 文件，并在顶部提供语言切换链接。
两种语言的命令示例应保持同步；代码注释、docstring 以及文档示例中的代码注释全部使用英文。
